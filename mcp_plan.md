# MCP Plan

## 1. Information I want AI to access automatically

- Database tables
- Table columns
- Primary keys
- Foreign keys
- Relationships between tables

## 2. MCP Server

I would use an open-source SQL Server MCP server to connect Claude Desktop with my local SQL Server database. This would allow the AI to understand the database schema automatically.

## 3. Benefits

With an MCP server, the AI can:
- Generate Entity Framework Core models
- Create DbContext
- Generate SQL queries
- Create Fluent API configurations
- Understand relationships without manually explaining the database
